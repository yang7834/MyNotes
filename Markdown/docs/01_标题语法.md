# 标题语法（推荐）

在单词或短语前面添加井号 (**#**)。**#** 的数量代表了标题的级别。

示例：
```
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

# 可选语法（不推荐）

在文本下方添加任意数量的 **=** 号来标识一级标题，或者 **-** 号来标识二级标题。

示例：
```
这是一级标题
==

这是二级标题
---
```

> 注意：不同的 Markdown 应用程序处理 # 和标题之间的空格方式并不一致。为了兼容考虑，请用一个空格在 # 和标题之间进行分隔。
