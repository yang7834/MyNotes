# 换行语法

在一行的末尾添加两个或多个空格，然后按回车键，即可创建一个换行。

示例：
```
This is the first line.<br>
And this is the second line.
```
![Pasted image 20260821150950](../assets/Pasted%20image%2020260821150950.png)

>注意：几乎每个 Markdown 应用程序都支持两个或多个空格进行换行，称为结尾空格的方式，但这是有争议的，因为很难在编辑器中直接看到空格，并且很多人在每个句子后面都会有意或无意地添加两个空格。由于这个原因，你可能要使用除结尾空格以外的其它方式来换行。幸运的是，几乎每个 Markdown 应用程序都支持另一种换行方式：HTML 的 `<br>` 标签。为了兼容性，请在行尾添加“**结尾空格**”或 HTML 的 **`<br>`** 标签来实现换行。
