# 特殊字符自动转义

在 HTML 文件中，有两个字符需要特殊处理： `<` 和 `&` 。 `<` 符号用于起始标签，`&` 符号则用于标记 HTML 实体，如果只是想要使用这些符号，必须要使用实体的形式，像是 `&lt;` 和 `&amp;`。

> 注意：Markdown 允许直接使用这些符号，它帮你自动转义字符

示例：
```
http://images.google.com/images?num=30&q=larry+bird

4 < 5
```
