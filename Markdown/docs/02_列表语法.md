# 有序列表

要创建有序列表，请在每个列表项前添加数字并紧跟一个英文句点。数字不必按数学顺序排列。

示例1：
```
1. First item
2. Second item
3. Third item
4. Fourth item
```
![[Pasted image 20260821134154.png]]

示例2：
```
1. First item
8. Second item
3. Third item
5. Fourth item
```
![[Pasted image 20260821134219.png]]

示例3：
```
1. First item
2. Second item
3. Third item
    1. Indented item
    2. Indented item
4. Fourth item
```
![[Pasted image 20260821134317.png]]
# 无序列表

要创建无序列表，请在每个列表项前面添加 减号 (**-**)、星号 (*****) 或加号 (**+**) 。个人推荐使用减号 (**-**) 来创建无序列表。缩进一个或多个列表项可创建嵌套列表。

示例1：
```
- First item
- Second item
- Third item
- Fourth item
```
![[Pasted image 20260821134355.png]]

示例2：
```
* First item
* Second item
* Third item
* Fourth item
```
![[Pasted image 20260821134554.png]]

示例3：
```
+ First item
+ Second item
+ Third item
+ Fourth item
```
![[Pasted image 20260821135020.png]]

示例4：
```
- First item
- Second item
- Third item
    - Indented item
    - Indented item
- Fourth item
```
![[Pasted image 20260821135237.png]]

# 在列表中嵌套其他元素

要在保留列表连续性的同时在列表中添加另一种元素，请将该元素缩进四个空格或一个制表符。

## 段落

示例：
```
*   This is the first list item.
*   Here's the second list item.

	I need to add another paragraph below the second list item.

*   And here's the third list item.
```
![[Pasted image 20260821140314.png]]

## 引用块

示例：
```
*   This is the first list item.
*   Here's the second list item.

    > A blockquote would look great below the second list item.

*   And here's the third list item.
```
![[Pasted image 20260821140336.png]]

## 列表

可以在有序列表中嵌套一个无序列表，反之亦然。

示例：
```
1. First item
2. Second item
3. Third item
    - Indented item
    - Indented item
4. Fourth item
```
![[Pasted image 20260821140800.png]]
