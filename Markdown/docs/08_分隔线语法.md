要创建分隔线，请在单独一行上使用三个或多个星号 (*******)、破折号 (**---**) 或下划线 (**___**) ，并且不能包含其他内容。

示例：
```
***
---
___
```
![Pasted image 20260821195736](../assets/Pasted%20image%2020260821195736.png)

>注意：为了兼容性，请在分隔线的前后均添加空白行。

示例：
```
Try to put a blank line before...

---

...and after a horizontal rule.
```
