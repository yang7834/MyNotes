## 1. 插件实现效果-[00:00](https://www.bilibili.com/video/BV1s6TF6hECB/?t=0)
- **痛点**：观看视频时频繁暂停录入笔记会打断学习节奏，严重削弱信息获取效率与内容理解的连贯性。
- **解决方案**：借助浏览器插件自动抓取网页文字，结合 AI 大模型生成结构化笔记。
- **核心功能**：
  - 自动生成章节总结、标题及对应的视频时间戳跳转链接。
  - 笔记正文下方附带完整逐字稿（Transcript），方便课后查缺补漏。
  - 点击笔记内的时间戳，Obsidian 右侧媒体组件可精准跳转至对应播放位置。

## 2. 两款插件介绍-[01:11](https://www.bilibili.com/video/BV1s6TF6hECB/?t=71)
- **Obsidian Web Clipper**：
  - 优势：交互极简，仅需 Chrome 扩展程序，免下载视频本体。
  - 特性：直接解析网页字幕或可见文本，Token 消耗极低，执行速度极快。
- **Billy Note**：
  - 需求：依赖外部后端服务完成视频下载与语音转文字（Speech-to-Text）。
  - 门槛：环境部署复杂，适用于无字幕源或高保真音频转录场景。
- **选型建议**：优先使用 `Obsidian Web Clipper`。官方原版仅兼容 YouTube，强烈建议使用社区维护的 `obsidian-clipper-cn` 汉化版（作者 next菜菜），该版本原生支持 B站 与 YouTube 双语环境。

## 3. 插件下载安装与基础配置-[02:08](https://www.bilibili.com/video/BV1s6TF6hECB/?t=128)
- **安装流程**：
  1. 前往插件 GitHub Releases 页面，下载最新压缩包（当前稳定版 v1.4.6）。
  2. 解压至本地固定目录。
  3. 浏览器访问 `chrome://extensions`，开启右上角开发者模式。
  4. 点击“加载已解压的扩展程序”，定向选择刚解压的文件夹。
  5. 确保扩展状态为已启用，并通过拼图图标将其固定至浏览器顶部工具栏。
- **基础参数**：
  - 界面语言：进入插件设置页，将 Language 切换为 Simplified Chinese。
  - 库绑定：在 General 设置中找到 Vault 字段，填入 Obsidian 本地库名，**必须按回车键**完成注册。
  - 配置重心：后续核心能力开发将聚焦于 Template（模板）模块。

## 4. 插件属性理解-[04:05](https://www.bilibili.com/video/BV1s6TF6hECB/?t=245)
- **模板管理与触发机制**：
  - 复制默认的 `default` 模板并重命名（如 `B站`），可大幅减少重复配置。
  - **触发规则（Trigger）**：设定插件生效的 URL 前缀。例：匹配全部 B站 视频只需填 `https://www.bilibili.com/video/`。若需精准正则匹配，可直接向 AI 索取表达式。
- **笔记生成策略**：
  - **写入模式**：视频学习笔记通常选择 `Create New Note`（新建），避免污染原始素材库。
  - **文件命名**：沿用内置变量 `"title"`（双引号标识动态变量），自动抓取网页主标题。
  - **归档路径**：指定目标文件夹（如 `Inbox`），便于后续使用 Dataview 或 Templater 统一清洗整理。

## 5. 自定义属性-[06:27](https://www.bilibili.com/video/BV1s6TF6hECB/?t=387)
- **动态变量体系**：
  - 插件通过系统预置变量自动渲染 Frontmatter 与正文。点击面板右上角 `⋯` 可调出全量变量面板（含 `author`, `content`, `transcript`, `meta` 等）。
  - 跨平台适配：GitHub 等站点可能缺少标准 `author` 字段。需在变量池中检索对应长路径标识符，复制后填入属性值框。
- **CSS 选择器精准抓取**：
  - 场景：需提取非标准字段（如 Repository Stars 计数）。
  - 工具：配合 `Selector Gadget` 浏览器插件。
  - 操作：单击目标元素标绿 → 按住 Shift 剔除同类冗余节点 → 确认右下角计数器为 `1` → 复制纯净 CSS Path。
  - 应用语法：在属性配置区输入 `{{selector:.target-element-class}}` 即可完成数据注入。
- **进阶处理**：若需对抓取结果进行正则清洗或类型强转，可查阅插件文档中的 Filter 机制实现自动化后处理。

## 6. 解释器与上下文-[13:19](https://www.bilibili.com/video/BV1s6TF6hECB/?t=799)
- **LLM 接入配置**：
  - 在侧边栏启用 `Interpreter`，按需填入第三方厂商的 Base URL 与 API Key（密钥仅加密存于本地，无云端泄露风险）。
  - 推荐模型：`deepseek-v4-flash` 或 Google Gemini。规避即将停服的老版接口，平衡推理速度与 Token 成本。
  - **上下文瘦身**：弃用耗油高的 `fullHTML`，改用 `content` 变量，仅向 AI 输送纯文本核心段落，显著压缩额度消耗。
- **智能总结与时间戳路由**：
  - **上下文拼装**：在模板上下文中并行传入 `"transcript"`（逐字稿）与 `"url"`（视频源地址）。
  - **Prompt 工程**：在提示词域使用双引号封装指令，要求模型按逻辑分段总结，并强制输出符合规范的跳转锚点。**关键约束：Prompt 字符串内严禁包含换行符，需压平为单行。**
  - **跳转协议**：B站 精确空降格式为 `?t=总秒数`；YouTube 为 `&t=总秒数`。需在指令中明确拼接逻辑，使 AI 输出的章节标题自动携带可点击协议头。
  - **正文延展**：在模板末尾追加 `---
{{transcript}}` 保留原始字幕底稿；利用 Markdown 链接语法将视频原链置于篇首。
- **生态扩展**：飞书文档等 SaaS 场景需提前录入企业级 App ID 与 Secret，以突破前端静态渲染限制，实现 DOM 级精准定位。

## AI总结
本教程系统拆解了 `obsidian-clipper-cn` 插件的工作流。从 Chrome 扩展部署、模板触发器编写，到利用 CSS Selector 抓取非标数据，最终通过接入 LLM 大模型实现基于逐字稿的结构化总结与精准时间戳跳转。掌握变量映射与单行 Prompt 编排后，可无缝复用于 B站、YouTube、GitHub 及各类企业内部知识库的高效知识萃取。
