## 1. 教程概述与准备工作-[00:00](https://www.bilibili.com/video/BV1eZdNB5EyL/?t=0)
- **工具定位**：SillyTavern 是一款免费、开源的前端界面，专为 AI 角色扮演设计。它整合了系统提示词管理与高级交互功能，有效规避市面 App 的高昂会员费与信息差收费。
- **运行逻辑**：前端负责界面与交互，需搭配独立的大语言模型后端方可使用。
- **内容规划**：本期保姆级教程涵盖前端安装、双后端部署方案、角色资产导入及核心参数调优。配套资源（角色卡、世界书、配置文件）已统一存放于评论区。

## 2. SillyTavern 本地部署安装-[00:55](https://www.bilibili.com/video/BV1eZdNB5EyL/?t=55)
- **环境要求**：需预先安装 Git，具备基础命令行操作经验。支持物理机或虚拟机环境。
- **安全目录创建**：务必新建专属文件夹（如 `SillyTavern`）并复制完整路径，严禁直接安装至系统盘根目录，以防权限冲突或文件清理困难。
- **自动化安装**：
  - 以管理员身份运行 PowerShell/CMD。
  - 使用 `cd` 命令切换至新建文件夹路径。
  - 粘贴官方 `git clone` 指令，等待源码与依赖下载完毕。
- **启动配置**：
  - 根据终端提示决定是否创建桌面快捷方式（Y/N）。
  - 安装完成后，双击快捷方式或进入目录运行启动脚本（如 `start_windows.bat`）。
  - 浏览器自动打开初始页面，选择中文后即可进入主页。

## 3. 后端模型部署：API 调用与 Ollama 本地运行-[03:59](https://www.bilibili.com/video/BV1eZdNB5EyL/?t=239)
- **云端 API 模式（强烈推荐）**：
  - **优势**：零硬件门槛，推理性能稳定且性价比高，最适合重度角色扮演。
  - **配置步骤**：在开放平台（如 DeepSeek 等）注册账号并创建 API Key。返回 SillyTavern，点击左侧插件接口图标，选择对应协议选项，粘贴 Key 并测试连通性。
  - **成本控制**：虽然按 Token 消耗计费，但选用高性价比第三方接口可大幅压缩日常体验成本。
- **本地 Ollama 模式**：
  - **优势**：完全离线、数据绝对隐私、无额外费用。
  - **劣势**：高度依赖显卡显存与算力，量化模型逻辑表现弱于云端旗舰 API，响应速度可能受限。
  - **配置步骤**：
    - 管理员 CMD 执行 `ollama pull <模型名>`（数值越大通常代表参数量与性能越强）。
    - 运行 `ollama run <模型名>` 唤醒本地推理服务。
    - 在 SillyTavern 插件设置中覆盖默认 URL 为本地地址，下拉选择已加载模型进行实测。

## 4. 角色卡与世界书导入配置-[08:34](https://www.bilibili.com/video/BV1eZdNB5EyL/?t=514)
- **状态校验**：务必确认后端已处于在线响应状态后再进行资源导入。
- **加载世界书（World Book）**：点击扩展管理面板，选择导入功能，读取 `.json` 格式的设定集文件。核对目录树确认信息完整载入。
- **加载角色卡（Character Card）**：同路径导入对应角色文件。
- **绑定关联**：在角色详情设置中启用“链接到世界书”选项，确保角色能实时调用预设的背景知识库，避免对话脱离人设。

## 5. 模型参数与提示词优化设置-[09:41](https://www.bilibili.com/video/BV1eZdNB5EyL/?t=581)
- **上下文与生成限制**：
  - Context Length（上下文窗口）：拉升至 `32768`
  - Max Reply Length（单次回复上限）：提升至 `8192`
  - ⚠️ 修改后必须手动点击 Save 保存。
- **采样策略调优**：
  - Temperature（创造性）：设定为 `0.7`，保障剧情连贯性的同时保留合理想象力。
  - Top_p（核采样概率）：设定为 `0.95`，过滤极端低概率词汇。
- **核心提示词注入**：展开系统提示词编辑区（System Prompt），将下载包内的 `system_prompts` 内容完整粘贴至主输入框。保存后重启会话生效。
