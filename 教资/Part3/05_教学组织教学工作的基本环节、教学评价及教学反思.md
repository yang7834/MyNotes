## 1. 教学组织形式-[00:00](https://www.bilibili.com/video/BV1AV411b7Sy?p=18&t=0)

### 1.1 古代教学组织形式：个别教学制
- **定义**：一对一教学，一个教师轮流教一个学生。
- **地位**：最古老的教学组织形式，古代中国、埃及、古希腊的学校多采用。

### 1.2 现代教学组织形式：班级授课制
- **定义**：集体教学形式，按年龄和文化程度编成固定班级，班级人数固定。
- **特点概括**：班、课、时。
  - **班**：以班为单位，按年龄、知识水平编班。
  - **课**：按学科、学年分成相互连接的多个部分，一节课一节课进行。
  - **时**：每节课固定时间（如45分钟），一门学科需完成规定课时。
- **发展历程**：
  - 1632年夸美纽斯《大教学论》系统论述班级授课制。
  - 中国1862年京师同文馆最早采用班级授课制（北京外国语大学前身之一）。
- **优缺点**（备考简答题）：
  - 优点：提高教学效率。
  - 缺点：不利于因材施教。

### 1.3 班级授课制的辅助形式
- **个别辅导**：针对个别学生的问题进行答疑、作业辅导。
- **现场教学**：带学生到生产/生活场所，获得直接经验（如参观工厂）。
- **复式教学**（特殊形式）：多在偏远地区，两个及以上班级合在一起，由同一教师交替教学。

### 1.4 其他教学组织形式
- **分组教学**：
  - 外部分组：按能力/成绩打破年龄编班。
  - 内部分组：在年龄编班内，再按能力/成绩分组。
- **设计教学法**：美国克伯屈提出（杜威的学生）。学生自己决定学习内容和设计学习活动，主张废除班级授课制和教科书。
- **道尔顿制**：美国伯克赫斯特提出。教师指定参考书，学生自学。
- **特朗普制**：大班上课 + 小班讨论 + 个人独立研究，又称“灵活的课程表”。

### 1.5 新型教学形式
- **小班教学**：控制班级规模（一般30人以内），保证教学质量。
- **翻转课堂**：课前观看教学视频，课上互动、答疑、讨论。
- **微课**：5~8分钟的视频，只讲一个知识点。
- **微格教学**：新教师面对少量学生（3~5人）上5至20分钟的完整课堂，录下视频自我分析提升。
- **慕课**：大规模在线开放课程，免费优质学习资源。

## 2. 教学工作的基本环节-[03:07](https://www.bilibili.com/video/BV1AV411b7Sy?p=18&t=187)

### 2.1 备课
- **地位**：上好课的先决条件/基础。
- **三备**：备教材、备学生、备教法。
- **三计划**：学期计划、单元计划、课时计划（教案）。
- **备课的基本要求**（重点备考简答题）：
  1. 深入准确把握学科课程标准和教学内容。
  2. 针对性地适应学生特点。
  3. 根据社会发展、科技变化不断更新备课内容。
  4. 做好课前各种准备。

### 2.2 上课
- **地位**：教学工作的中心环节，提高教学质量的关键。
- **课的类型**：
  - 按教学任务：新授课、巩固课、技能课、检查课。
  - 按完成任务数量：单一课（一个任务）、综合课（两个及以上任务）。
  - 按教学方法：讲授课、演示课、练习课、实验课、复习课。
- **上好课的具体要求**（备考简答题）：
  1. 目标明确。
  2. 内容科学正确。
  3. 方法得当。
  4. 结构合理。
  5. 语言艺术。
  6. 板书清晰规范。
  7. 态度自信，肢体语言丰富。
  8. 充分发挥学生主体性（最根本要求）。
- **记忆口诀**：慕容芳气购泰语书。

### 2.3 课外作业的布置与批改
- **地位**：课堂教学的延续和补充。
- **布置作业的要求**（重点备考简答题）：
  1. 内容符合学科课程标准。
  2. 分量适宜、难度适宜。
  3. 与教科书内容有逻辑联系。
  4. 有助于启发学生思维。
  5. 理论联系实际。
  6. 提出明确要求，规定完成时间。
- **记忆口诀**：按标准、量适宜、有逻辑、启思维、联实际、明要求。

### 2.4 课外辅导
- **地位**：上课的必要补充。
- **注意**：指校内教师正常辅导，不是校外补课。

### 2.5 学生学业成绩的评价
- **方式**：考察（口头提问、书面作业、书面测试）和考试（期中、期末）。
- **测验的指标**：
  - **信度**（reliability）：测验结果可靠、稳定。无标准。
  - **效度**（validity）：测验能测出想要测的东西。有标准。
  - **难度**：试题难易程度应适中。难度值和难度成反比。
  - **区分度**（discrimination）：能区分不同水平学生。

## 3. 教学评价-[01:05:11](https://www.bilibili.com/video/BV1AV411b7Sy?p=18&t=3911)

### 3.1 教学评价的种类
- **按功能分**：
  - 诊断性评价：教学前，摸底考试/把脉。
  - 形成性评价：教学过程中，档案袋/口头提问/随堂小测。
  - 总结性评价：教学后，期末考试/终结考试。
- **按评价标准分**：
  - 相对性评价（常模参照）：看排名，与他人比较，如教师招聘考试。
  - 绝对性评价（目标参照）：看是否达到固定标准，如合格考试60分及格。
  - 个体内差异评价：自己和自己比，看进步。

### 3.2 教学评价的功能（备考简答题）
1. **导向功能**：指挥棒作用，指引教学/学习方向。
2. **诊断功能**：发现问题，如体检。
3. **调节功能**：解决问题，调整教学。
4. **激励功能**：调动教师教学积极性和学生学习动力。
5. **管理功能**：达到预期目的，约束功效。

### 3.3 小学教学评价的方法与步骤
- **步骤**：建立评价目标 → 搜集评价信息 → 报告评价结果。
- **评价目标**：
  - 与学业成绩直接相关：知识技能、学习态度/兴趣/习惯。
  - 与学业成绩间接相关：智能、性格、家庭环境、身体健康。
- **搜集评价信息方法**：观察、作业检查、考试、家访、纪实记录法。
- **评价报告内容**：学业成绩、学习特点、特殊品质、兴趣特长等。

## 4. 教学反思-[01:24:33](https://www.bilibili.com/video/BV1AV411b7Sy?p=18&t=4473)

### 4.1 教学反思的概念
- 教师对自己的教学行为进行审视和分析的过程。
- 教师成长公式（波斯纳）：经验 + 反思 = 教师成长。

### 4.2 教学反思的内容
1. 教学理念（最根本，如以学生发展为本）。
2. 教学过程（教学设计、教学方法）。
3. 教学得失（成功经验与不足之处）。
4. 教学再设计（基于得失重新设计）。

### 4.3 教学反思的类型
- 按基本流程：教学前反思、教学中反思（调控性反思）、教学后反思。
- 按主体：自我反思、集体反思。
- 按对象：纵向反思（放入历史时间维度）、横向反思（跳出自我，学习他人）。
- 按理论深浅：理论反思、经验反思。

### 4.4 教学反思的方法
- 行动研究法、自我提问法、教学诊断法、比较法、阅读新知法。
