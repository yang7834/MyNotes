## 1. 教师观概述与整体框架-[00:00](https://www.bilibili.com/video/BV1Ga4y1i77D?p=7&t=0)
- 本视频进入职业理念部分，核心主题是**教师观**。
- 教师观需掌握主要内容，并能应用于**材料分析题**。
- 大前提：我国正在推行**素质教育**，教师观在新课程改革（新课改）背景下讨论。
- 整体框架包括两个维度：
  - **教师角色的转变**：从传统角色转向新课程要求的角色。
  - **教师行为的转变**：在师生关系、教学、自我、其他教育者四个方面的行为变化。

## 2. 教师角色的转变-[02:03](https://www.bilibili.com/video/BV1Ga4y1i77D?p=7&t=123)
教师角色转变包含以下四个方面：

### 2.1 学生引导者和发展的促进者-[02:03](https://www.bilibili.com/video/BV1Ga4y1i77D?p=7&t=123)
- 传统教育中教师是知识灌输者，只重考试成绩。
- 新时代知识更新快，教师应教会学生**学习方法与探索能力**，即“授人以鱼不如授人以渔”。
- 同时引导学生**思想品德和人格发展**，教师是“灯塔”，指明前进方向。
- 材料题关键词：引导、促进、探索、实践、品德引导。

### 2.2 课程建设者和开发者-[05:26](https://www.bilibili.com/video/BV1Ga4y1i77D?p=7&t=326)
- 传统教师照本宣科，按国家统一教材授课。
- 新教师应发挥主动性，参与课程建设、开发校本课程、补充教学资料、编写讲义/教材。
- 我国实行**三级课程管理**：国家课程、地方课程、校本课程（选择题常考）。
- 材料题关键词：开发课程、编纂讲义、参与校本课程、补充参考资料。

### 2.3 教育教学的研究者-[08:52](https://www.bilibili.com/video/BV1Ga4y1i77D?p=7&t=532)
- 教师需以研究者眼光审视教学中的问题。
- 过程：发现问题 → 思考分析 → 反思讨论 → 总结经验改进教学。
- 常见表现：写论文、做课题、研究学生问题。
- 材料题关键词：研究、反思、论文、课题、解决问题。

### 2.4 社区型的开放教师-[10:21](https://www.bilibili.com/video/BV1Ga4y1i77D?p=7&t=621)
- 教师不应局限于学校和课堂，要走向社区。
- 挖掘社区教育资源（如邀请民警讲防骗、消防员讲消防）。
- 为社区提供教育服务（如给家长开设家庭教育讲座）。
- 此知识点在材料题和选择题中很少考查。

### 2.5 记忆口诀-[12:15](https://www.bilibili.com/video/BV1Ga4y1i77D?p=7&t=735)
- 口诀：**“见醋放盐”**（谐音“减速放盐”），从每个角色中提取关键字组合而成。
- 看到关键字要迅速对应完整句子，可用于考试时快速回忆。

## 3. 教师行为的转变-[13:12](https://www.bilibili.com/video/BV1Ga4y1i77D?p=7&t=792)
教师行为转变包含四个“对待”：

### 3.1 对待师生关系：尊重与赞赏-[13:12](https://www.bilibili.com/video/BV1Ga4y1i77D?p=7&t=792)
- 师生身份平等，教师不再是绝对权威。
- 尊重学生人格和自尊心，不体罚、不嘲笑、不当众批评。
- 尤其要尊重“差生”，引导其进步。
- 善于发现学生优点，学会赞赏（如绘画天赋、热心肠等）。

### 3.2 对待教学：帮助与引导-[15:39](https://www.bilibili.com/video/BV1Ga4y1i77D?p=7&t=939)
- 本质上和“学生引导者/促进者”角色一致。
- 循循善诱，让学生主动探索、发现。
- 材料中若出现教师启发引导，可同时对应此行为与角色。

### 3.3 对待自我：反思-[16:39](https://www.bilibili.com/video/BV1Ga4y1i77D?p=7&t=999)
- 核心是**反思**，教学前、教学中、教学后都要反思。
- 具体反思内容在后续课程中展开。

### 3.4 对待其他教育者：合作-[17:08](https://www.bilibili.com/video/BV1Ga4y1i77D?p=7&t=1028)
- 核心是**合作**，优秀学生培养需要各科老师配合。
- 出色课程设计需要同事共同调研、讨论。

### 3.5 记忆口诀-[18:06](https://www.bilibili.com/video/BV1Ga4y1i77D?p=7&t=1086)
- 口诀：**“你它我他”**（或“四个对待”）
  - 你 → 学生（师生关系）
  - 它 → 教学
  - 我 → 自我（反思）
  - 他 → 其他教育者（合作）
- 也可记成“对待学生、对待教学、对待自我、对待他者”。

## 4. 答题模板与实战分析-[19:03](https://www.bilibili.com/video/BV1Ga4y1i77D?p=7&t=1143)
### 4.1 答题模板
- **总**：根据教师观，材料中教师的行为是正确/错误的，体现了XXX。
- **分**：理论点+材料分析（每点2-3句）。
- **总**：总结该行为对教育教学的意义。
（模板与教育观、学生观一致，只是替换为教师观内容。）

### 4.2 真题示例：曲老师
- 材料：曲老师在农村中学教历史8年，拒绝城区学校邀请；经常翻阅期刊、了解学科前沿；提升研究能力并解决问题；每天坚持阅读，弥补大学知识不足。
- 分析要点：
  1. **教育教学研究者**：翻阅期刊、提升研究方法、解决问题 → 体现研究者的角色。
  2. **对待自我（反思）**：不满足已有知识，每天阅读、不断提升自我。
  3. **对待其他教育者（合作）**：材料中提到其他同事，可联系合作要求（依据材料灵活判断）。
- 参考：最终答案不唯一，言之有理即可。
