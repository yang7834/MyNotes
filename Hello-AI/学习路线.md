# 不同背景，不同入口

## 零基础 （约 2-3 周）

从头走，别跳。

1. [什么是 AI](https://unclecheng-li.github.io/Hello-AI/basics/what-is-ai/) — 先知道这张地图有多大
2. [什么是 LLM](https://unclecheng-li.github.io/Hello-AI/basics/what-is-llm/) — 理解聊天模型怎么生成文字
3. [Prompt 基础](https://unclecheng-li.github.io/Hello-AI/prompt/prompt-basic/) — 学会怎么跟模型说人话
4. [Chat 类产品怎么用](https://unclecheng-li.github.io/Hello-AI/tools/chat-products/) — 把学到的东西用起来

这四篇是最小起步单元。读完就能跟 AI 有效对话了。

## 有编程基础 （约 1-2 周）

可以跳过 AI 基础前三篇，直接从 LLM 开始。

1. [什么是 LLM](https://unclecheng-li.github.io/Hello-AI/basics/what-is-llm/) — 快速补上模型侧的知识
2. [API 入门](https://unclecheng-li.github.io/Hello-AI/tools/api/) — 开始写代码调模型
3. [RAG](https://unclecheng-li.github.io/Hello-AI/rag/) — 给模型接上你自己的资料
4. [Agent](https://unclecheng-li.github.io/Hello-AI/agent/) — 让模型自己拆任务、调工具

API 入门可能半小时就过完了，RAG 和 Agent 才是真正花时间的地方。

## 想快速做项目 （约 1 周）

两三天速读基础概念，然后直接进实战。

1. 速读 [AI 基础](https://unclecheng-li.github.io/Hello-AI/basics/) 里的「如果时间有限」四篇
2. 直接进 [Build 实战](https://unclecheng-li.github.io/Hello-AI/build/)
3. 挑一个 [Lab](https://unclecheng-li.github.io/Hello-AI/lab/) 动手做

走完这条线手里就能有一个能跑的小项目。去年 Vibe Coding 出来之后，有博主实测零基础一周做出了三个小工具。

---

几个常见的坑：
- **死磕理论不动手**
- **工具贪多**
- **跳过基础冲 Agent**
- **追求完美架构**
