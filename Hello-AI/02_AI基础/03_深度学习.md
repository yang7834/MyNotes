## 1. 什么是深度学习

深度学习（Deep Learning）就是让计算机用多层神经网络，一层一层地从数据里抽丝剥茧，学会人类难以用规则描述的复杂模式。

流程：**输入**（原始数据：像素/声波/文字）→ **层层提炼**（自动学出抽象特征）→ **输出**（复杂任务判断）。

## 2. 这章解决什么问题

上一章讲了机器学习的基本思路：给计算机看例子，让它自己找规律。但如果规律太复杂、太抽象，人根本写不出规则，怎么办？

以识别猫的照片为例：可以尝试写规则（尖耳朵、胡须、圆瞳孔），但猫的睡姿千奇百怪，光线角度千变万化，规则根本列不完。理解一句话的意思更复杂。

深度学习解决这个问题：不用人写规则，模型自己从原始数据里一层一层提炼越来越抽象的特征。底层识别边缘和颜色，中层识别耳朵和尾巴，高层识别“这是一只猫”。人只需准备数据、调整结构。

- 先搞懂原理：神经网络基本结构与层级分工

- 了解历史：2012 年 AlexNet 改变了一切
- 分清边界：深度学习 vs 传统机器学习

## 3. 神经网络：用「层级流水线」做判断

深度学习的核心是**神经网络（Neural Network）**。它是对人脑（约860亿个神经元）的简化数学模拟。可以把神经网络想象成工厂流水线，每一层工人负责一道工序。

### 3.1 三层基本结构

一个基础神经网络有三层：

![Mermaid Diagram](https://unclecheng-li.github.io/Hello-AI/assets/mermaid/deep-learning_mermaid_0_085ee251.svg)

- **输入层（Input Layer）**：接收原始数据。图像则每个节点对应一个像素的亮度/颜色值；文本则是每个词的数字编码。
- **隐藏层（Hidden Layer）**：真正干活的地方。每个神经元对上一层输出做加权求和，再通过激活函数决定是否“开火”传递信号。例如第一层识别“横线”，第二层识别“横线+竖线像耳朵”，第三层识别“耳朵+圆脑袋是猫”。层数越多，模式越抽象。
- **输出层（Output Layer）**：给出最终判断。猫狗分类中输出“是猫的概率”和“是狗的概率”，概率高者胜出。

### 3.2 权重：每个连接的「重要性分数」

层与层之间的每条连线都有一个数值叫**权重（Weight）**，决定上一层的某个信号对下一层某个神经元的影响大小。

例：判断一个人是否会违约，考虑收入、负债率、学历。若认为收入最重要给权重0.6，负债率0.3，学历0.1。神经网络中权重成千上万，训练时自动调整。

训练过程就是不断调整权重。调整算法叫**反向传播（Backpropagation）**：模型做完一题，对照答案算出差，然后从输出层往回一层层“追责”，告诉每一层该往哪个方向改。

### 3.3 激活函数：决定要不要传递信号

如果神经元只是简单相加，多层和一层无区别（线性运算无法学复杂规律）。**激活函数（Activation Function）**打破线性，像一个开关：输入信号够强就输出非零值，否则输出零或接近零。

ReLU（修正线性单元）最常用：输入大于零原样输出，小于等于零输出零。类比公司审批——预算超门槛往上递，否则驳回。

非线性让神经网络能拟合弯曲复杂的关系，而非只能画直线。

### 3.4 梯度消失与梯度爆炸：深层网络的「走极端」问题

反向传播时梯度从输出层逐层传回。每层乘以小于1的系数，传到前几层梯度接近零，权重无法更新，即**梯度消失**；每层乘以大于1的系数，梯度不断膨胀成天文数字，权重跳飞，即**梯度爆炸**。

2015年微软亚洲研究院提出**ResNet（残差网络）**，通过“跳过连接”让梯度直接从后面的层流到前面的层，解决此难题。ResNet做到152层，在图像分类上首次超越人类水平。

## 4. 为什么叫「深度」学习

「深度」指神经网络的隐藏层很多。传统神经网络1~2个隐藏层，深度学习动辄几十层、上百层甚至上千层。

层数多带来的好处：**模型能学习不同抽象层次的特征。**

以图像识别为例：
- 第1~2层：边缘、颜色块、简单纹理
- 第3~5层：眼睛、耳朵、轮子、翅膀等基本部件
- 第6~10层：“猫脸”“汽车轮廓”“建筑结构”等整体概念
- 更深层：场景关系，如“一只猫趴在沙发上”

传统机器学习需人工设计特征（如SIFT），深度学习直接丢原始像素进去，模型自己学特征。

## 5. 深度学习的突破：2012 年的那一声惊雷

深度学习并非2012年发明。1986年反向传播已提出，但之后几十年神经网络被冷落——层数一多就训练不动。

转折点：**2012年**，Geoffrey Hinton 带着学生 Alex Krizhevsky 和 Ilya Sutskever，用 **AlexNet** 深度卷积神经网络参加 **ImageNet 大规模视觉识别挑战赛**（120万张图片、1000类分类）。AlexNet top-5错误率 **15.3%**，第二名传统方法 **26.2%**，领先近11个百分点，碾压性胜利。

关键里程碑表格：

| 年份 | 里程碑 | 意义 |
| --- | --- | --- |
| 1943 | McCulloch-Pitts 神经元模型 | 神经网络的数学鼻祖 |
| 1958 | 感知机（Perceptron） | 第一个能「学习」的算法模型 |
| 1986 | 反向传播算法（Backpropagation） | 让多层网络训练成为可能 |
| 1998 | LeNet-5 用于手写数字识别 | 第一个商用的卷积神经网络 |
| 2006 | Hinton 提出深度信念网络 | 「深度学习」概念复兴的起点 |
| 2012 | AlexNet 在 ImageNet 夺冠 | 深度学习革命元年，GPU算力觉醒 |
| 2014 | GoogLeNet、VGGNet | 错误率压到 7% 以下 |
| 2015 | ResNet（残差网络） | 152层首次超越人类，残差连接解决梯度问题 |
| 2017 | Transformer 架构发表 | 彻底改变自然语言处理走向 |
| 2020 | GPT-3 1750亿参数 | 大语言模型暴力美学时代开启 |
| 2022 | ChatGPT 发布 | 大模型进入公众视野，AIGC 爆发 |

AlexNet 成功三原因：
1. **数据量够大**：ImageNet 120万张标注图片
2. **GPU 算力**：两块 NVIDIA GTX 580，训练速度比CPU快几十倍
3. **技术改进**：ReLU 激活函数和 Dropout 正则化，解决梯度消失和过拟合

2012年后深度学习席卷AI领域：
- **图像识别**：人脸识别、医学影像、自动驾驶感知
- **语音识别**：从高斯混合模型切换到端到端深度网络
- **自然语言处理**：2017年Transformer出现后，机器翻译、文本生成、问答全面转向深度学习，催生大语言模型

## 7. 深度学习 vs 传统机器学习

| 对比维度 | 传统机器学习 | 深度学习 |
| --- | --- | --- |
| 特征怎么处理 | 人手工设计，需要领域经验 | 模型自动从原始数据里学 |
| 数据需求量 | 几百到几千条就能跑 | 通常需要几万到几百万条 |
| 模型结构 | 相对简单，可解释性强 | 层数多、参数多，像黑盒 |
| 算力要求 | 普通电脑就能跑 | 通常需要 GPU 加速 |
| 擅长的问题 | 结构化数据（表格、数字） | 图像、语音、文本等非结构化数据 |
| 调参难度 | 相对直接 | 需要设计网络结构、调学习率等，门槛更高 |

类比：传统机器学习像“老师手把手教学生”——老师整理笔记（特征工程）；深度学习像“学生自己泡图书馆”——在海量资料中自己总结。

注意：数据只有几千条表格记录时，简单随机森林或XGBoost可能效果更好，训练快、好解释、省资源。选对工具更重要。

## 8. 最小示例：感受「分层学习」

思想实验：教「视觉系统」识别猫。

- **第一层（边缘检测）**：横线、竖线、斜线、颜色边界。
- **第二层（部件组合）**：横线+竖线=角，曲线围成圆。
- **第三层（部件识别）**：圆+三角=猫耳朵，椭圆+圆点=猫眼睛。
- **第四层（整体判断）**：猫耳朵+猫眼睛+胡须+圆脸 → 这是猫。

可找一张猫的照片，不断模糊，观察自己何时认不出猫。边缘和轮廓先消失，但整体轮廓还在时仍能认出——说明大脑也在做分层特征提取。

## 9. 需要警惕的事：算法偏见与深度伪造

### 9.1 算法偏见：COMPAS 再犯预测系统

2016年，ProPublica 调查了法院常用的 **COMPAS** 系统（用深度学习预测再犯风险分数，法官据此判决）。发现：**黑人被告被预测为高风险的概率是白人被告的近两倍（45% vs 23%）**，而实际再犯率几乎相同。

根源：训练数据中的历史偏见（司法系统对黑人社区的系统性歧视）被模型放大。这是技术正义问题——当深度学习进入司法、贷款、招聘等高风险领域，数据偏见会被算法放大。

### 9.2 深度伪造：你的脸可能被用来造假

**DeepFake** 是深度学习在视频领域的阴暗面。GAN（生成对抗网络）能生成逼真假视频——换脸、表情操纵、口型同步，无需专业技能。

案例：2019年伪造名人视频；2022年有人用深度伪造冒充公司CEO要求转账，导致香港一家公司被骗2亿港元。

应对：**内容溯源**——数字水印和AI检测工具，但这是持续的猫鼠游戏。

## 11. 常见误区

**误区 1：深度学习 = 人工智能**  
深度学习只是实现AI的众多技术之一。AI还包括规则系统、知识图谱、进化算法等。大语言模型基于深度学习，但自动驾驶路径规划、推荐系统协同过滤等很多模块并不用深度网络。

**误区 2：层数越多越好**  
层数增加提升表达能力，但代价：训练困难（梯度消失/爆炸）、过拟合风险、推理变慢。ResNet靠残差连接才做到152层，不是无脑堆层。

**误区 3：深度学习不需要特征工程**  
深度学习能自动学特征，但“准备数据”没消失：需要决定输入什么、清洗、增强、标注。

**误区 4：传统方法已经过时了**  
数据量小、需强可解释性、资源受限场景下，传统机器学习仍是不二之选。银行风控、医院辅助诊断、制造业异常检测常使用逻辑回归、随机森林。

## 15. 练习题 / 小实验

### 练习 1：深度学习在图像和语言任务上表现特别好，但在表格数据上往往不如传统机器学习。为什么？

> 💡 提示：从「特征的结构化程度」「数据量」「特征的层次性」三个角度思考。

**参考答案**

**思路 1：结构化程度**  
图像和语言是非结构化数据，深度学习擅长自动提炼特征；表格数据本身结构化，传统机器学习需要的人工特征工程优势更明显。

**思路 2：数据量**  
深度学习需海量数据，互联网图片/文本丰富，但企业销售记录往往只有几千到几万条，不足时深度学习易过拟合，传统机器学习更稳健。

**思路 3：特征的层次性**  
图像和语言有天然层次结构（像素→边缘→部件→概念；字→词→句→段），深度神经网络能捕捉；表格特征通常无嵌套层次，简单线性模型或树模型足够。

**综合结论**：图像和语言是非结构化、海量、有层次；表格是结构化、小数据、无层次。二者各有所长。

### 练习 2：残差连接（Skip Connection）解决了什么问题？怎么工作？

**参考答案**

**核心问题：梯度消失**  
反向传播梯度每经过一层乘一个系数（激活函数导数），层数多且系数小于1时梯度指数衰减到零，前面几层学不到东西。

**工作方式**  
正常层：输入 $x$ 通过权重层得到 $Wx$，再经激活函数得 $f(Wx)$。  
残差连接加捷径：输出 $= f(Wx) + x$。  
求导时：$\\frac{d}{dx}(f(Wx) + x) = f'(Wx)W + 1$，那个 $+1$ 保证梯度至少是1，不会消失。就像拥堵路上开应急车道。

### 练习 3：训练猫狗分类模型，训练 loss 下降但验证 loss 上升，是什么问题？如何解决？

**参考答案**

**问题定性：过拟合（Overfitting）**  
训练 loss 下降说明模型在“记住”训练数据；验证 loss 上升说明泛化变差。

**可能原因**  
- 模型太复杂（层数/参数多），容量过大
- 训练数据不足，数据增强不够
- 训练轮次过多，没有提前停止

**解决思路**  
1. 增加数据量：数据增强（翻转、裁剪、颜色抖动）
2. 正则化：Dropout、L2 正则化
3. 简化模型：减少层数或神经元数
4. 早停（Early Stopping）：监控验证 loss，开始上升前停止
5. 批归一化（Batch Normalization）：稳定输入分布，加速训练且略有正则化效果

### 练习 4（实验题）：手机人脸识别对墨镜、侧脸、暗光的容忍度

**参考思路**

现代手机人脸识别对墨镜、侧脸、暗光有不错鲁棒性。深度学习学到了“不变特征”：如五官几何关系（两眼距离、口鼻相对位置）在遮挡/角度/光线变化下仍保持；整体轮廓和肤色分布；上下文信息（背景、发型、衣着）。训练数据包含各种条件，模型被迫学习跨条件成立的特征。这是相对手工规则的核心优势。
